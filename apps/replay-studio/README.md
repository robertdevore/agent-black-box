# replay-studio

Owns UI assets and playback. Fixed IMPORTER/PUBLISHER bindings connect independently deployed services. ASSETS contains only public-safe fixtures and UI.

Build from repository root: `npm run build --workspace @agent-black-box/replay-studio`.

The app manifest uses Composer contract 1. Deployment is explicit; see ../../docs/DEPLOYMENT.md. Data version 1 migrations belong to this application. No remote repository or Cloudflare resource is created by building.
